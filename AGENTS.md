# Команды агента

Используйте эти команды для проверки целостности кодовой базы после внесения изменений.

## Линтинг и статический анализ
Запуск статического анализа для поиска ошибок и предупреждений во всех пакетах.
`melos run analyze`

## Тестирование
Запуск всех тестов во всех пакетах.
`melos run test`

## Форматирование
Форматирование Dart-кода во всем рабочем пространстве.
`melos run format`

## Управление зависимостями
Bootstrap рабочего пространства для установки всех зависимостей.
`melos run bootstrap`

## Очистка
Очистка артефактов сборки во всех пакетах.
`melos run clean`
