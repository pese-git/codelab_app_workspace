# 🛠️ Спецификации UI компонентов (Техническое задание)

Подробные требования к каждому компоненту для обеспечения единообразия с референсным приложением.

---

## 1. Компоненты Оболочки Приложения (Application Shell)

### 1.1 Navigation Pane (Боковая панель)
**Базовая технология**: `NavigationPane` из библиотеки `fluent_ui`.
**Требования**:
- **Режимы**: 
    - `compact`: Ширина ~64px (Project Rail).
    - `expanded`: Ширина ~250-300px (Project/Workspace Panel).
- **Элементы**:
    - `PaneItem`: Навигация по различным воркспейсам/проектам.
    - `PaneItemSeparator`: Разделитель между основным меню и нижними действиями.
    - `PaneItemFooter`: (Настройки, Справка).
- **Визуал**:
    - Темная тема (Фон: `#202020`, Поверхность: `#2B2B2B`).
    - Индикатор выбора: Тонкое выделение (Акцентный цвет или `#333333`).
- **Взаимодействие**: Поддержка логики `Draggable` (если это возможно в рамках ограничений `NavigationPane`).

### 1.2 Title Bar (Заголовок окна)
**Требования**:
- **Содержимое**: Элементы управления окном (Свернуть, Развернуть, Закрыть) в крайней правой части.
- **Стиль**: Бесшовное слияние с фоном приложения.
- **Взаимодействие**: Область, за которую можно перетаскивать окно (реализация зависит от платформы).

## 2. Компоненты Экрана Home

### 2.1 Карточка проекта (Project Card)
**Требования**:
- **Содержимое**: Название проекта, дата последнего изменения, иконка.
- **Состояние**: Состояния при наведении (Hover) и нажатии (Pressed).
- **Визуал**: Минималистичный дизайн, чистые границы или легкая тень.

### 2.2 Empty State (Пустое состояние)
**Требования**:
- **Содержимое**: Иллюстрация или иконка, текст "Проекты не найдены", кнопка "Создать новый проект".

---

## 3. Компоненты Интерфейса Сессии (Session Interface)

### 3.1 Message Timeline (Лента сообщений)
**Требования**:
- **Структура**: `ListView.builder` для высокой производительности.
- **Типы элементов**:
    - `UserMessage`: Только текст или Текст + Файлы.
    *   `AiMessage`: Текст + Markdown + Результаты инструментов/Блоки кода.
- **Визуал**: Четкое визуальное различие (пузыри или фон) между Пользователем и AI.

### 3.2 Prompt Composer (Поле ввода)
**Требования**:
- **Ввод**: `TextField` с автоматическим увеличением высоты.
- **Функционал**:
    - Иконка вложения файла.
    - Выбор инструмента/агента.
    - Кнопка "Отправить".
- **Логика**: Интеграция с `flutter_bloc` для управления состоянием (изменение текста, добавление файлов).

### 3.3 File Tabs System (Система вкладок)
**Требования**:
- **Структура**: Стиль `TabBar`.
- **Функционал**: Кнопка закрытия (X) на каждой вкладке, индикатор активной вкладки.
- **Контент**: Вкладки для `.dart`, `.py`, `.txt` и `Terminal`.

## 4. Дизайн-токены (Reference)
- **Цвета (Dark Theme)**:
    - `Background`: `#121212`
    - `Surface`: `#1E1E1E`
    - `Accent`: `Fluent Accent Blue`
    - `TextPrimary`: `#FFFFFF`
    - `TextSecondary`: `#9A9A9A` (dark) / `#8F8D88` (light)
- **Отступы (Spacing)**: 4px, 8px, 12px, 16px, 24px.
