# Задача 5.2 — InitializeUseCase & CreateSessionUseCase

## Цель

Реализовать Use Cases для инициализации ACP соединения и создания новой сессии.

## Концепция

Аналог Python: `application/use_cases.py::InitializeUseCase` и `CreateSessionUseCase`.

**Жизненный цикл:**
1. `InitializeUseCase.execute()` — подключается, отправляет `initialize`, получает capabilities
2. `CreateSessionUseCase.execute()` — опционально аутентифицируется, создаёт сессию через `session/new`

---

## Шаг 1 — InitializeUseCase

Создай файл `lib/application/use_cases/initialize_use_case.dart`:

```dart
import 'package:fpdart/fpdart.dart';
import 'package:structured_log/structured_log.dart';

import '../../core/error/failures.dart';
import '../../domain/entities/acp_message.dart';
import '../../domain/entities/initialize_result.dart';
import '../../domain/services/transport_service.dart';
import '../dto/session_dto.dart';

/// Use Case для инициализации соединения с ACP сервером
///
/// Выполняет handshake: подключение + `initialize` запрос.
/// После успешного выполнения transport остаётся подключённым.
/// Регистрируется в AppModule как transient.
class InitializeUseCase {
  final _log = getLogger('InitializeUseCase');
  final TransportService _transport;

  InitializeUseCase({required TransportService transport})
      : _transport = transport;

  Future<Either<Failure, InitializeResponseDto>> execute(
    InitializeRequestDto request,
  ) async {
    _log.info('InitializeUseCase: connecting to ${request.serverHost}:${request.serverPort}');

    try {
      // Подключаемся
      await _transport.connect();
      _log.debug('Connected to server');

      // Отправляем initialize request
      final initRequest = AcpMessage.request(
        'initialize',
        params: {
          'protocolVersion': 1,
          'clientCapabilities': {
            'fs': {
              'readTextFile': true,
              'writeTextFile': true,
            },
            'terminal': true,
          },
          'clientInfo': {
            'name': 'acp-flutter-client',
            'version': '1.0.0',
          },
        },
      );

      await _transport.send(initRequest.toJson());
      _log.debug('Sent initialize request id=${initRequest.id}');

      // Получаем ответ
      final responseData = await _transport.receive(
        requestId: initRequest.id.toString(),
      );

      final response = AcpMessage.fromJson(responseData);

      if (response.hasError) {
        await _transport.disconnect();
        return left(ProtocolFailure(
          message: 'Initialize failed: ${response.error!.message}',
          errorCode: response.error!.code,
        ));
      }

      final result = response.result as Map<String, dynamic>;
      final capabilities = result['agentCapabilities'] as Map<String, dynamic>? ?? {};
      final authMethods = (result['authMethods'] as List<dynamic>?)
          ?.cast<Map<String, dynamic>>() ?? [];
      final protocolVersion = result['protocolVersion']?.toString() ?? '1';

      // Сохраняем capabilities в transport
      _transport.setServerCapabilities(capabilities);

      _log.info('InitializeUseCase: success, protocolVersion=$protocolVersion');

      return right(InitializeResponseDto(
        serverCapabilities: capabilities,
        availableAuthMethods: authMethods,
        protocolVersion: protocolVersion,
      ));
    } on TransportFailure catch (f) {
      return left(f);
    } on ProtocolFailure catch (f) {
      return left(f);
    } catch (e) {
      await _transport.disconnect();
      return left(UnexpectedFailure(message: 'Initialize failed: $e'));
    }
  }
}
```

## Шаг 2 — CreateSessionUseCase

Создай файл `lib/application/use_cases/create_session_use_case.dart`:

```dart
import 'package:fpdart/fpdart.dart';
import 'package:structured_log/structured_log.dart';

import '../../core/error/failures.dart';
import '../../domain/entities/acp_message.dart';
import '../../domain/entities/session.dart';
import '../../domain/repositories/session_repository.dart';
import '../../domain/services/transport_service.dart';
import '../dto/session_dto.dart';

/// Use Case для создания новой ACP сессии
///
/// Предполагает, что InitializeUseCase уже выполнен.
/// Аналог Python: application/use_cases.py::CreateSessionUseCase
/// Регистрируется в AppModule как transient.
class CreateSessionUseCase {
  final _log = getLogger('CreateSessionUseCase');
  final TransportService _transport;
  final SessionRepository _sessionRepo;

  CreateSessionUseCase({
    required TransportService transport,
    required SessionRepository sessionRepo,
  })  : _transport = transport,
        _sessionRepo = sessionRepo;

  Future<Either<Failure, CreateSessionResponseDto>> execute(
    CreateSessionRequestDto request,
  ) async {
    _log.info('CreateSessionUseCase: cwd=${request.cwd}');

    try {
      if (!_transport.isInitialized()) {
        return left(SessionFailure(
          message: 'Transport not initialized. Call InitializeUseCase first.',
        ));
      }

      // Опциональная аутентификация
      if (request.authMethod != null && request.authCredentials != null) {
        final authResult = await _authenticate(
          request.authMethod!,
          request.authCredentials!,
        );
        if (authResult != null) return left(authResult);
      }

      // Создаём сессию через session/new
      final sessionRequest = AcpMessage.request(
        'session/new',
        params: {
          'cwd': request.cwd,
          'clientCapabilities': request.clientCapabilities ?? {},
        },
      );

      await _transport.send(sessionRequest.toJson());

      final responseData = await _transport.receive(
        requestId: sessionRequest.id.toString(),
      );

      final response = AcpMessage.fromJson(responseData);

      if (response.hasError) {
        return left(ProtocolFailure(
          message: 'session/new failed: ${response.error!.message}',
          errorCode: response.error!.code,
        ));
      }

      final result = response.result as Map<String, dynamic>;
      final sessionId = result['sessionId'] as String?;

      if (sessionId == null) {
        return left(ProtocolFailure(
          message: 'Server response missing sessionId',
        ));
      }

      // Создаём и сохраняем доменную сущность
      final session = Session.create(
        serverHost: request.serverHost,
        serverPort: request.serverPort,
        clientCapabilities: request.clientCapabilities ?? {},
        serverCapabilities: _transport.getServerCapabilities(),
        sessionId: sessionId,
        cwd: request.cwd,
      );

      await _sessionRepo.save(session);

      _log.info('Session created: $sessionId');

      return right(CreateSessionResponseDto(
        sessionId: sessionId,
        serverCapabilities: session.serverCapabilities,
        isAuthenticated: request.authMethod != null,
      ));
    } on Failure catch (f) {
      return left(f);
    } catch (e) {
      return left(UnexpectedFailure(message: 'CreateSession failed: $e'));
    }
  }

  Future<Failure?> _authenticate(
    String authMethod,
    Map<String, dynamic> credentials,
  ) async {
    final authRequest = AcpMessage.request(
      'authenticate',
      params: {'authMethod': authMethod, ...credentials},
    );

    await _transport.send(authRequest.toJson());
    final responseData = await _transport.receive(
      requestId: authRequest.id.toString(),
    );
    final response = AcpMessage.fromJson(responseData);

    if (response.hasError) {
      return AuthFailure(
        message: 'Authentication failed: ${response.error!.message}',
      );
    }
    return null;
  }
}
```

## Критерии готовности

- [ ] `InitializeUseCase` возвращает `Either<Failure, InitializeResponseDto>`
- [ ] `CreateSessionUseCase` возвращает `Either<Failure, CreateSessionResponseDto>`
- [ ] Оба Use Case зарегистрированы в `AppModule` как transient
- [ ] Обработка ошибок через `Failure` типы
- [ ] `_transport.setServerCapabilities()` вызывается после initialize
- [ ] Сессия сохраняется в `SessionRepository` после создания
