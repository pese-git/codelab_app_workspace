# Задача 7.1 — App Setup & Navigation

## Цель

Настроить корневое Flutter-приложение с `go_router`, `fluent_ui`, `ScopeWidget` (cherrypick) и иерархией `BlocProvider`.

> **Важно:** Приложение `apps/codelab_desktop` уже реализовано и содержит `CodeLabAppBootstrap`, `GoRouter`, `DialogHost`, `HomeScreen`, `SessionScreen`. Задача — интегрировать ACP BLoC-слой в существующую структуру, не заменяя и не дублируя готовый UI.

---

## Шаг 1 — App Widget

Создай файл `lib/presentation/app.dart`:

```dart
import 'package:fluent_ui/fluent_ui.dart';
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:cherrypick_flutter/cherrypick_flutter.dart';
import 'package:go_router/go_router.dart';
import 'package:codelab_ui_components/codelab_ui_components.dart';

import '../core/di/injection.dart';
import 'blocs/session/session_bloc.dart';
import 'blocs/chat/chat_bloc.dart';
import 'blocs/permission/permission_bloc.dart';
import 'router/app_router.dart';

class App extends StatelessWidget {
  const App({super.key});

  @override
  Widget build(BuildContext context) {
    return ScopeWidget(
      scope: rootScope,
      child: MultiBlocProvider(
        providers: [
          BlocProvider<SessionBloc>(
            create: (_) => rootScope.resolve<SessionBloc>(),
          ),
          BlocProvider<ChatBloc>(
            create: (_) => rootScope.resolve<ChatBloc>(),
          ),
        ],
        child: FluentApp.router(
          title: 'ACP Client',
          themeMode: ThemeMode.dark,
          theme: AppTheme.light,
          darkTheme: AppTheme.dark,
          routerConfig: AppRouter.router,
        ),
      ),
    );
  }
}
```

> `AppTheme.light` и `AppTheme.dark` — из `codelab_ui_components`. Не создавай свою тему — используй готовую.

## Шаг 2 — Router

Создай файл `lib/presentation/router/app_router.dart`:

```dart
import 'package:go_router/go_router.dart';

import '../screens/connect_screen.dart';
import '../screens/session_list_screen.dart';
import '../screens/chat_screen.dart';

class AppRouter {
  static final router = GoRouter(
    initialLocation: '/connect',
    routes: [
      GoRoute(
        path: '/connect',
        name: 'connect',
        builder: (context, state) => const ConnectScreen(),
      ),
      GoRoute(
        path: '/sessions',
        name: 'sessions',
        builder: (context, state) => const SessionListScreen(),
      ),
      GoRoute(
        path: '/chat/:sessionId',
        name: 'chat',
        builder: (context, state) {
          final sessionId = state.pathParameters['sessionId']!;
          return ChatScreen(sessionId: sessionId);
        },
      ),
    ],
  );
}
```

## Шаг 3 — Connect Screen

Создай файл `lib/presentation/screens/connect_screen.dart`:

```dart
import 'package:fluent_ui/fluent_ui.dart';
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:go_router/go_router.dart';
import 'package:codelab_ui_components/codelab_ui_components.dart';

import '../blocs/session/session_bloc.dart';
import '../blocs/session/session_event.dart';
import '../blocs/session/session_state.dart';

class ConnectScreen extends StatefulWidget {
  const ConnectScreen({super.key});

  @override
  State<ConnectScreen> createState() => _ConnectScreenState();
}

class _ConnectScreenState extends State<ConnectScreen> {
  final _hostController = TextEditingController(text: 'localhost');
  final _portController = TextEditingController(text: '8080');

  @override
  Widget build(BuildContext context) {
    return BlocListener<SessionBloc, SessionState>(
      listener: (context, state) {
        if (state is SessionListLoaded || state is SessionInitialized) {
          context.goNamed('sessions');
        }
      },
      child: SimpleShell(
        child: Center(
          child: ConstrainedBox(
            constraints: const BoxConstraints(maxWidth: 360),
            child: Column(
              mainAxisSize: MainAxisSize.min,
              crossAxisAlignment: CrossAxisAlignment.stretch,
              children: [
                const Text('ACP Client', style: TextStyle(fontSize: 24)),
                const SizedBox(height: 32),
                AppTextField(
                  controller: _hostController,
                  label: 'Server Host',
                  placeholder: 'localhost',
                ),
                const SizedBox(height: 12),
                AppTextField(
                  controller: _portController,
                  label: 'Port',
                  placeholder: '8080',
                ),
                const SizedBox(height: 24),
                BlocBuilder<SessionBloc, SessionState>(
                  builder: (context, state) {
                    return AppButton(
                      onPressed: state is SessionLoading
                          ? null
                          : () => context.read<SessionBloc>().add(
                                SessionEvent.initialize(
                                  serverHost: _hostController.text,
                                  serverPort:
                                      int.tryParse(_portController.text) ?? 8080,
                                ),
                              ),
                      label: 'Connect',
                      isLoading: state is SessionLoading,
                      fullWidth: true,
                    );
                  },
                ),
              ],
            ),
          ),
        ),
      ),
    );
  }

  @override
  void dispose() {
    _hostController.dispose();
    _portController.dispose();
    super.dispose();
  }
}
```

> Используй `SimpleShell` из `codelab_ui_components` — без titleBar достаточно для экрана подключения.
> `AppTextField` и `AppButton` — из `codelab_ui_components`, не Material-виджеты.

## Связь с codelab_desktop

Если ACP-клиент интегрируется в существующее приложение `apps/codelab_desktop`:

- Добавь `MultiBlocProvider` с ACP BLoC-ами внутри существующего `CodeLabAppBootstrap.build()`
- Маршруты ACP (`/connect`, `/sessions`, `/chat/:sessionId`) регистрируются в существующем `buildRouter()` из `apps/codelab_desktop/lib/app/navigation/router.dart`
- `ScopeWidget` оборачивает всё дерево в `CodeLabAppBootstrap.build()`

---

## Критерии готовности

- [ ] `App` виджет использует `FluentApp.router` с `AppTheme` из `codelab_ui_components`
- [ ] `ScopeWidget` оборачивает `MultiBlocProvider`
- [ ] `go_router` настроен с маршрутами `/connect`, `/sessions`, `/chat/:sessionId`
- [ ] `ConnectScreen` использует `SimpleShell`, `AppTextField`, `AppButton`
- [ ] Навигация после успешного `initialize` → `/sessions`
