
# Задача 7.1 - Production Desktop Shell Architecture (Flutter + fluent_ui + cherrypick)

## Цель

Построить production-ready desktop shell для AI IDE приложения уровня OpenCode Desktop / Cursor / Claude Desktop на Flutter Desktop.

Архитектура должна быть:

- desktop-first
- keyboard-first
- modular
- testable
- scalable 2+ years
- максимально использовать `fluent_ui`
- использовать scoped dependency injection через `cherrypick`
- поддерживать многосессионную работу
- готовой к multi-window future

# Главный App Bootstrap

Файл:

```text
app/bootstrap/app.dart
```

```dart
class CodeLabApp extends StatefulWidget {
  const CodeLabApp({super.key});

  @override
  State<CodeLabApp> createState() => _CodeLabAppState();
}

class _CodeLabAppState extends State<CodeLabApp> {
  late final Scope _rootScope;
  late final GoRouter _router;

  @override
  void initState() {
    super.initState();

    _rootScope = createRootScope();
    _router = _rootScope.resolve<GoRouter>();
  }

  @override
  void dispose() {
    _rootScope.close();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return DiScope(
      scope: _rootScope,
      child: FluentApp.router(
        title: 'CodeLab Desktop',
        debugShowCheckedModeBanner: false,
        theme: AppTheme.light,
        darkTheme: AppTheme.dark,
        routerConfig: _router,
        builder: (context, child) {
          return OverlayHost(
            child: WindowShell(
              child: child ?? const SizedBox.shrink(),
            ),
          );
        },
      ),
    );
  }
}
```

# Lifecycle

```dart
class _SessionHostState extends State<SessionHost> {
  late final Scope _scope;

  @override
  void initState() {
    super.initState();

    final root = context.resolve<Scope>();

    _scope = root.openSubScope('session:${widget.sessionId}')
      ..installModules([
        SessionModule(widget.sessionId),
      ]);
  }

  @override
  void dispose() {
    _scope.close();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return DiScope(
      scope: _scope,
      child: MultiBlocProvider(
        providers: [
          BlocProvider(
            create: (_) => _scope.resolve<ChatBloc>(),
          ),
          BlocProvider(
            create: (_) => _scope.resolve<TerminalBloc>(),
          ),
          BlocProvider(
            create: (_) => _scope.resolve<PermissionBloc>(),
          ),
        ],
        child: const SessionScreen(),
      ),
    );
  }
}
```

# Performance правила

## Нельзя:

- rebuild whole shell on message stream
    
- держать huge list in setState
    
- heavy controller god object
    

## Нужно:

- BlocBuilder granular
    
- ValueListenableBuilder local state
    
- selectors
    
- virtualized lists

CodeLabAppController stores everything
