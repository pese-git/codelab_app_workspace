# Задача 7.4 — Permission Dialog

## Цель

Модальный диалог для запросов разрешения от ACP агента. Показывает что агент хочет сделать и предлагает варианты ответа.

> **Важно:** `apps/codelab_desktop` уже содержит `DialogHost` для управления диалогами. При интеграции — показывай `PermissionDialog` через существующий `DialogHost.showDialog()`, а не напрямую через `showDialog`.

---

## Шаг 1 — Permission Dialog Widget

Создай файл `lib/presentation/widgets/permission_dialog.dart`:

```dart
import 'package:fluent_ui/fluent_ui.dart';
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:codelab_ui_components/codelab_ui_components.dart';

import '../../infrastructure/services/permission_handler.dart';
import '../../domain/entities/permission.dart';
import '../blocs/permission/permission_bloc.dart';
import '../blocs/permission/permission_event.dart';

class PermissionDialog extends StatelessWidget {
  final PendingPermissionRequest request;

  const PermissionDialog({super.key, required this.request});

  @override
  Widget build(BuildContext context) {
    return ContentDialog(
      title: Row(
        children: [
          AppIcon(
            _iconForKind(request.toolCall.kind),
            size: AppIconSize.md,
          ),
          const SizedBox(width: AppSpacing.sm),
          Expanded(
            child: Text(
              request.toolCall.title ?? 'Permission Required',
            ),
          ),
        ],
      ),
      content: Column(
        mainAxisSize: MainAxisSize.min,
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Badge(
            label: 'Tool: ${request.toolCall.toolCallId}',
            variant: BadgeVariant.neutral,
          ),
          const SizedBox(height: AppSpacing.xs),
          Badge(
            label: 'Session: ${request.sessionId}',
            variant: BadgeVariant.info,
          ),
          const SizedBox(height: AppSpacing.md),
          const Text('Choose an option:'),
        ],
      ),
      actions: [
        AppButton(
          onPressed: () => context.read<PermissionBloc>().add(
                PermissionEvent.cancelled(
                  requestId: request.requestId.toString(),
                ),
              ),
          label: 'Cancel',
          variant: ButtonVariant.tertiary,
        ),
        ...request.options.map(
          (option) => _PermissionOptionButton(
            option: option,
            requestId: request.requestId.toString(),
          ),
        ),
      ],
    );
  }

  IconData _iconForKind(dynamic kind) {
    if (kind == null) return FluentIcons.shield;
    return switch (kind.toString()) {
      'read' => FluentIcons.view,
      'edit' => FluentIcons.edit,
      'delete' => FluentIcons.delete,
      'execute' => FluentIcons.command_prompt,
      'fetch' => FluentIcons.download,
      _ => FluentIcons.shield,
    };
  }
}

class _PermissionOptionButton extends StatelessWidget {
  final PermissionOption option;
  final String requestId;

  const _PermissionOptionButton({
    required this.option,
    required this.requestId,
  });

  @override
  Widget build(BuildContext context) {
    final isAllowOption = option.kind == PermissionKind.allowOnce ||
        option.kind == PermissionKind.allowAlways;

    return AppButton(
      onPressed: () => context.read<PermissionBloc>().add(
            PermissionEvent.optionSelected(
              requestId: requestId,
              optionId: option.optionId,
            ),
          ),
      label: option.name,
      variant: isAllowOption ? ButtonVariant.primary : ButtonVariant.destructive,
    );
  }
}
```

> Используй компоненты из `codelab_ui_components`:
>
> - `ContentDialog` (fluent_ui) — вместо `AlertDialog` из Material
> - `AppButton` с `ButtonVariant.primary` / `ButtonVariant.destructive` / `ButtonVariant.tertiary`
> - `AppIcon` — иконка типа операции
> - `Badge` с `BadgeVariant.neutral` / `BadgeVariant.info` — метаданные запроса

---

## Критерии готовности

- [ ] Диалог использует `ContentDialog` (fluent_ui)
- [ ] Tool call ID и session ID показаны через `Badge`
- [ ] Allow options — `AppButton` с `ButtonVariant.primary`
- [ ] Reject/deny options — `AppButton` с `ButtonVariant.destructive`
- [ ] Cancel — `AppButton` с `ButtonVariant.tertiary`
- [ ] Выбор option вызывает `PermissionBloc.add(PermissionOptionSelected)`
