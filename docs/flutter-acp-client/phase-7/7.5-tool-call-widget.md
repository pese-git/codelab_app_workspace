# Задача 7.5 — Tool Call Widget

## Цель

Виджет для отображения tool call с прогрессом выполнения: иконка типа, статус, заголовок, затронутые файлы.

> **Важно:** `MessageBubble` из `codelab_ui_components` уже реализован и используется через `MessageTimeline`. Для tool calls создаётся отдельный `ToolCallCard`, поскольку это не сообщение чата, а событие выполнения инструмента.

---

## Шаг 1 — Tool Call Card

Создай файл `lib/presentation/widgets/tool_call_card.dart`:

```dart
import 'package:fluent_ui/fluent_ui.dart';
import 'package:codelab_ui_components/codelab_ui_components.dart';

import '../../domain/entities/tool_call_record.dart';
import '../../domain/entities/tool_call.dart';

class ToolCallCard extends StatelessWidget {
  final ToolCallRecord toolCall;

  const ToolCallCard({super.key, required this.toolCall});

  @override
  Widget build(BuildContext context) {
    final brightness = FluentTheme.of(context).brightness;
    final colors = brightness == Brightness.light
        ? AppColors.light
        : AppColors.dark;

    return Container(
      margin: const EdgeInsets.symmetric(vertical: AppSpacing.xs2),
      padding: const EdgeInsets.all(AppSpacing.sm),
      decoration: BoxDecoration(
        color: colors.surfaceSubtle,
        borderRadius: AppRadius.mdAll,
        border: Border.all(color: colors.borderBase),
      ),
      child: Row(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          _buildStatusIndicator(toolCall.status, toolCall.kind),
          const SizedBox(width: AppSpacing.sm),
          Expanded(
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Text(
                  toolCall.title,
                  style: AppTypography.bodyMedium(color: colors.textStrong),
                ),
                if (toolCall.locations != null &&
                    toolCall.locations!.isNotEmpty) ...[
                  const SizedBox(height: AppSpacing.xs2),
                  ...toolCall.locations!.map(
                    (loc) => Text(
                      loc.line != null
                          ? '${loc.path}:${loc.line}'
                          : loc.path,
                      style: AppTypography.caption(color: colors.textMuted),
                      maxLines: 1,
                      overflow: TextOverflow.ellipsis,
                    ),
                  ),
                ],
              ],
            ),
          ),
          const SizedBox(width: AppSpacing.sm),
          _buildStatusBadge(toolCall.status),
        ],
      ),
    );
  }

  Widget _buildStatusIndicator(ToolCallStatus status, ToolKind? kind) {
    if (status == ToolCallStatus.inProgress) {
      return const AppProgressRing(size: 20, strokeWidth: 2);
    }
    return AppIcon(_iconForKind(kind), size: AppIconSize.sm);
  }

  Widget _buildStatusBadge(ToolCallStatus status) {
    return switch (status) {
      ToolCallStatus.pending =>
        const Badge('Pending', variant: BadgeVariant.neutral),
      ToolCallStatus.inProgress =>
        const Badge('Running', variant: BadgeVariant.primary),
      ToolCallStatus.completed =>
        const Badge.success('Done'),
      ToolCallStatus.failed =>
        const Badge.error('Failed'),
      ToolCallStatus.cancelled =>
        const Badge('Cancelled', variant: BadgeVariant.neutral),
    };
  }

  IconData _iconForKind(ToolKind? kind) {
    return switch (kind) {
      ToolKind.read => FluentIcons.view,
      ToolKind.edit => FluentIcons.edit,
      ToolKind.delete => FluentIcons.delete,
      ToolKind.execute => FluentIcons.command_prompt,
      ToolKind.search => FluentIcons.search,
      ToolKind.fetch => FluentIcons.download,
      ToolKind.think => FluentIcons.brain,
      _ => FluentIcons.settings,
    };
  }
}
```

> Используй компоненты из `codelab_ui_components`:
>
> - `AppProgressRing` — заменяет `CircularProgressIndicator` (in-progress состояние)
> - `Badge` с вариантами — заменяет кастомный `_StatusChip` (`BadgeVariant.success`, `.error`, `.neutral`, `.primary`)
> - `AppIcon` — заменяет `Icon(icon, size: 20)` с правильными размерами
> - `AppColors` / `AppTypography` / `AppSpacing` / `AppRadius` — токены дизайна
>
> `MessageBubble` уже реализован в `codelab_ui_components` и используется внутри `MessageTimeline`.
> Создавать кастомный `MessageBubble` в `lib/presentation/widgets/` **не нужно**.

## Критерии готовности

- [ ] `ToolCallCard` показывает `AppProgressRing` для in-progress состояния
- [ ] `Badge` с правильным вариантом отображает статус
- [ ] Затронутые файлы (`locations`) показаны через `AppTypography.caption`
- [ ] Компонент использует `AppColors` / `AppSpacing` / `AppRadius` из дизайн-системы
