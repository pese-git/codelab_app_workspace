# Задача 7.2 — Session List Screen

## Цель

Экран со списком доступных сессий на ACP сервере. Позволяет создать новую или открыть существующую.

> **Важно:** `apps/codelab_desktop` уже содержит `HomeScreen` с `Sidebar`/`SidebarSession` для отображения сессий. Новый экран нужен только если ACP-клиент работает как отдельное приложение. При интеграции в `codelab_desktop` — подключи `SessionBloc` к существующему `HomeScreen`.

---

## Шаг 1 — Session List Screen

Создай файл `lib/presentation/screens/session_list_screen.dart`:

```dart
import 'package:fluent_ui/fluent_ui.dart';
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:go_router/go_router.dart';
import 'package:codelab_ui_components/codelab_ui_components.dart';

import '../blocs/session/session_bloc.dart';
import '../blocs/session/session_event.dart';
import '../blocs/session/session_state.dart';
import '../blocs/chat/chat_bloc.dart';
import '../blocs/chat/chat_event.dart';
import '../../application/dto/session_dto.dart';

class SessionListScreen extends StatelessWidget {
  const SessionListScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return DesktopShell(
      titleBar: TitleBar(
        title: 'Sessions',
        trailing: AppIconButton(
          icon: FluentIcons.refresh,
          onPressed: () =>
              context.read<SessionBloc>().add(const SessionEvent.listSessions()),
        ),
      ),
      content: BlocConsumer<SessionBloc, SessionState>(
        listener: (context, state) {
          if (state is SessionActive) {
            context.read<ChatBloc>().add(
                  ChatEvent.sessionOpened(sessionId: state.sessionId),
                );
            context.goNamed('chat', pathParameters: {
              'sessionId': state.sessionId,
            });
          }
        },
        builder: (context, state) {
          return switch (state) {
            SessionLoading() => const Center(
                child: AppProgressRing(),
              ),
            SessionListLoaded(:final listResponse) =>
              _SessionList(sessions: listResponse.sessions),
            SessionError(:final message) => Center(
                child: ErrorState(
                  title: 'Error',
                  message: message,
                  actionLabel: 'Retry',
                  onAction: () => context
                      .read<SessionBloc>()
                      .add(const SessionEvent.listSessions()),
                ),
              ),
            _ => const Center(
                child: EmptyState(
                  title: 'No connection',
                  message: 'Connect to an ACP server first',
                ),
              ),
          };
        },
      ),
      sidebar: _NewSessionButton(),
    );
  }
}

class _NewSessionButton extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.all(AppSpacing.md),
      child: AppButton(
        onPressed: () => _showCreateSessionDialog(context),
        label: 'New Session',
        icon: FluentIcons.add,
        fullWidth: true,
      ),
    );
  }

  void _showCreateSessionDialog(BuildContext context) {
    final cwdController = TextEditingController();

    showDialog<void>(
      context: context,
      builder: (dialogContext) => ContentDialog(
        title: const Text('New Session'),
        content: AppTextField(
          controller: cwdController,
          label: 'Working Directory',
          placeholder: '/home/user/project',
        ),
        actions: [
          AppButton(
            onPressed: () => Navigator.of(dialogContext).pop(),
            label: 'Cancel',
            variant: ButtonVariant.tertiary,
          ),
          AppButton(
            onPressed: () {
              Navigator.of(dialogContext).pop();
              context.read<SessionBloc>().add(
                    SessionEvent.createSession(cwd: cwdController.text),
                  );
            },
            label: 'Create',
          ),
        ],
      ),
    );
  }
}

class _SessionList extends StatelessWidget {
  final List<SessionListItemDto> sessions;

  const _SessionList({required this.sessions});

  @override
  Widget build(BuildContext context) {
    if (sessions.isEmpty) {
      return const Center(
        child: EmptyState(
          title: 'No sessions yet',
          message: 'Create a session to get started',
          icon: FluentIcons.chat,
        ),
      );
    }

    return ListView.builder(
      padding: const EdgeInsets.symmetric(
        horizontal: AppSpacing.md,
        vertical: AppSpacing.sm,
      ),
      itemCount: sessions.length,
      itemBuilder: (context, index) {
        final session = sessions[index];
        return Padding(
          padding: const EdgeInsets.only(bottom: AppSpacing.xs),
          child: ListItem(
            title: session.title ?? session.sessionId,
            subtitle: session.cwd,
            leading: const AppIcon(FluentIcons.chat_bubbles),
            trailing: session.updatedAt != null
                ? Text(
                    session.updatedAt!.substring(0, 10),
                    style: const TextStyle(fontSize: 11),
                  )
                : null,
            onTap: () => context.read<SessionBloc>().add(
                  SessionEvent.loadSession(sessionId: session.sessionId),
                ),
          ),
        );
      },
    );
  }
}
```

> Используй компоненты из `codelab_ui_components`:
>
> - `DesktopShell` — главный layout вместо `Scaffold`
> - `TitleBar` — заголовок экрана
> - `AppProgressRing` — индикатор загрузки
> - `EmptyState` / `ErrorState` — пустое состояние и ошибка
> - `ListItem` — элемент списка сессий
> - `AppButton` + `ButtonVariant.tertiary` — для действий
> - `AppTextField` — поле ввода в диалоге
> - `ContentDialog` (fluent_ui) — модальный диалог
> - `AppIconButton` — кнопка refresh в заголовке

---

## Критерии готовности

- [ ] Список сессий отображается через `ListItem`
- [ ] `EmptyState` показывается при пустом списке
- [ ] `ErrorState` показывается при ошибке
- [ ] Диалог "New Session" использует `ContentDialog` + `AppTextField`
- [ ] Нажатие на сессию → загрузка и переход в `/chat/:sessionId`
- [ ] `AppProgressRing` показывается во время загрузки
