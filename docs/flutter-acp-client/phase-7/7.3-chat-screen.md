# Задача 7.3 — Chat Screen (Streaming)

## Цель

Главный экран чата: список сообщений со streaming, поле ввода промпта, план агента и tool calls.

> **Важно:** `apps/codelab_desktop` уже реализует `SessionScreen` + `SessionRegion` + `ChatPanel` с `MessageTimeline` и `PromptComposer`. Не создавай дублирующий экран — используй существующую реализацию и подключи к ней `ChatBloc`.

---

## Шаг 1 — Chat Screen

Создай файл `lib/presentation/screens/chat_screen.dart`:

```dart
import 'package:fluent_ui/fluent_ui.dart';
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:codelab_ui_components/codelab_ui_components.dart';

import '../blocs/chat/chat_bloc.dart';
import '../blocs/chat/chat_event.dart';
import '../blocs/chat/chat_state.dart';
import '../blocs/permission/permission_bloc.dart';
import '../blocs/permission/permission_state.dart';
import '../widgets/tool_call_card.dart';
import '../widgets/plan_panel.dart';
import '../widgets/permission_dialog.dart';

class ChatScreen extends StatelessWidget {
  final String sessionId;

  const ChatScreen({super.key, required this.sessionId});

  @override
  Widget build(BuildContext context) {
    return BlocListener<PermissionBloc, PermissionState>(
      listener: (context, state) {
        if (state is PermissionAwaitingDecision) {
          showDialog<void>(
            context: context,
            barrierDismissible: false,
            builder: (_) => BlocProvider.value(
              value: context.read<PermissionBloc>(),
              child: PermissionDialog(request: state.request),
            ),
          );
        }
        if (state is PermissionIdle || state is PermissionResolved) {
          Navigator.of(context, rootNavigator: true).maybePop();
        }
      },
      child: DesktopShell(
        titleBar: TitleBar(
          title: sessionId,
          trailing: BlocBuilder<ChatBloc, ChatState>(
            builder: (context, state) {
              if (!state.isProcessing) return const SizedBox.shrink();
              return AppButton(
                onPressed: () =>
                    context.read<ChatBloc>().add(const ChatEvent.promptCancelled()),
                label: 'Stop',
                icon: FluentIcons.stop,
                variant: ButtonVariant.secondary,
                size: ButtonSize.sm,
              );
            },
          ),
        ),
        content: Column(
          children: [
            // Панель плана агента (скрыта если план пуст)
            _PlanPanel(),
            // Список сообщений и tool calls
            Expanded(child: _ChatArea()),
            // Поле ввода промпта
            _PromptInputArea(),
          ],
        ),
      ),
    );
  }
}

class _ChatArea extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return BlocBuilder<ChatBloc, ChatState>(
      builder: (context, state) {
        if (!state.hasMessages && state.toolCalls.isEmpty) {
          return const Center(
            child: EmptyState(
              title: 'Start a conversation',
              message: 'Send a message to the agent',
              icon: FluentIcons.chat,
            ),
          );
        }

        // Конвертируем domain ChatMessage → ui Message для MessageTimeline
        final uiMessages = state.messages.map((m) => Message(
          id: m.id,
          role: m.role == ChatMessageRole.user
              ? MessageRole.user
              : MessageRole.assistant,
          content: m.text.isEmpty && m.status == ChatMessageStatus.streaming
              ? '...'
              : m.text,
        )).toList();

        return Column(
          children: [
            // Сообщения чата
            Expanded(
              child: MessageTimeline(messages: uiMessages),
            ),
            // Tool calls (если есть)
            if (state.hasToolCalls)
              ConstrainedBox(
                constraints: const BoxConstraints(maxHeight: 200),
                child: ListView(
                  padding: const EdgeInsets.symmetric(
                    horizontal: AppSpacing.md,
                    vertical: AppSpacing.xs,
                  ),
                  children: state.toolCalls.values
                      .map((tc) => ToolCallCard(toolCall: tc))
                      .toList(),
                ),
              ),
          ],
        );
      },
    );
  }
}

class _PlanPanel extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return BlocBuilder<ChatBloc, ChatState>(
      buildWhen: (prev, curr) => prev.plan != curr.plan,
      builder: (context, state) {
        if (!state.hasPlan) return const SizedBox.shrink();
        return PlanPanel(plan: state.plan);
      },
    );
  }
}

class _PromptInputArea extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return BlocBuilder<ChatBloc, ChatState>(
      buildWhen: (prev, curr) => prev.isProcessing != curr.isProcessing,
      builder: (context, state) {
        return Padding(
          padding: const EdgeInsets.all(AppSpacing.md),
          // PromptComposer из codelab_ui_components:
          // обрабатывает Enter/Cmd+Enter, multi-line, авто-фокус
          child: PromptComposer(
            onSend: state.isProcessing
                ? (_) {}
                : (text) => context
                    .read<ChatBloc>()
                    .add(ChatEvent.promptSubmitted(text: text)),
            placeholder: state.isProcessing
                ? 'Agent is thinking...'
                : 'Send a message...',
          ),
        );
      },
    );
  }
}
```

> Ключевые компоненты из `codelab_ui_components`:
>
> - `MessageTimeline` — список сообщений с авто-скроллом и markdown рендерингом (заменяет `ListView.builder` + кастомный `MessageBubble`)
> - `PromptComposer` — поле ввода с Enter/Cmd+Enter отправкой (заменяет `_PromptInput`)
> - `DesktopShell` + `TitleBar` — layout вместо `Scaffold` + `AppBar`
> - `EmptyState` — пустое состояние чата

## Конвертация ChatMessage → Message

`MessageTimeline` принимает `List<Message>` из `codelab_ui_components`, а `ChatBloc` работает с `List<ChatMessage>` из domain. Конвертация происходит прямо в `_ChatArea.build()`:

```dart
final uiMessages = state.messages.map((m) => Message(
  id: m.id,
  role: m.role == ChatMessageRole.user
      ? MessageRole.user
      : MessageRole.assistant,
  content: m.text,
)).toList();
```

Streaming-индикатор встроен в `MessageBubble` (внутри `MessageTimeline`) через рендеринг markdown.
Для явного индикатора streaming передавай `'...'` как контент пока `status == ChatMessageStatus.streaming`.

## Связь с codelab_desktop

`SessionScreen` в `apps/codelab_desktop` уже использует:

- `SessionRegion` → `ChatPanel` с `MessageTimeline`
- `PromptComposer`
- `DesktopShell` с боковой панелью файлов и терминалом

При интеграции ACP-клиента в `codelab_desktop` — подключай `ChatBloc` к существующему `ChatPanel`, не создавая дублирующий экран.

## Критерии готовности

- [ ] `ChatScreen` использует `DesktopShell` + `TitleBar`
- [ ] `MessageTimeline` из `codelab_ui_components` отображает сообщения

- [ ] Кнопка Stop доступна во время обработки
- [ ] `EmptyState` показывается при отсутствии сообщений
