# Задача 3.2 — Repository Interfaces

## Цель

Определить абстрактные интерфейсы репозиториев в Domain Layer. Конкретные реализации будут в Infrastructure Layer (задача 4.5).

## Принцип

Dependency Inversion Principle (SOLID): Domain Layer определяет интерфейс, Infrastructure Layer его реализует. Use Cases зависят от абстракции, не от конкретной реализации.

---

## Шаг 1 — Session Repository

Создай файл `lib/domain/repositories/session_repository.dart`:

```dart
import '../entities/session.dart';

/// Интерфейс репозитория для управления ACP сессиями
///
/// Определяет контракт для хранения и получения сессий.
/// Реализации: [InMemorySessionRepository], (будущее) LocalStorageSessionRepository
abstract interface class SessionRepository {
  /// Сохраняет или обновляет сессию
  Future<void> save(Session session);

  /// Загружает сессию по ID
  /// Возвращает null если сессия не найдена
  Future<Session?> load(String sessionId);

  /// Удаляет сессию по ID
  Future<void> delete(String sessionId);

  /// Возвращает все сохранённые сессии
  Future<List<Session>> getAll();

  /// Очищает все сессии
  Future<void> clear();
}
```

## Шаг 2 — Chat History Repository

Создай файл `lib/domain/repositories/chat_history_repository.dart`:

```dart
import '../entities/chat_message.dart';

/// Интерфейс репозитория для истории сообщений чата
///
/// Хранит сообщения, привязанные к конкретной сессии.
abstract interface class ChatHistoryRepository {
  /// Добавляет сообщение в историю сессии
  Future<void> addMessage(String sessionId, ChatMessage message);

  /// Обновляет существующее сообщение (например, при завершении streaming)
  Future<void> updateMessage(String sessionId, ChatMessage message);

  /// Загружает всю историю сессии
  Future<List<ChatMessage>> getHistory(String sessionId);

  /// Очищает историю сессии
  Future<void> clearHistory(String sessionId);
}
```

## Критерии готовности

- [ ] `SessionRepository` абстрактный интерфейс определён
- [ ] `ChatHistoryRepository` абстрактный интерфейс определён
- [ ] Нет конкретных реализаций в domain слое
- [ ] Нет импортов из infrastructure/presentation
