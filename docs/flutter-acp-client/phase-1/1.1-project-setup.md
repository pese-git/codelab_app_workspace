# Задача 1.1 — Структура проекта и зависимости

## Цель

Создать Flutter-проект с правильной структурой папок (Clean Architecture) и настроить все необходимые зависимости.

## Предварительные требования

- Flutter SDK >= 3.19
- Dart SDK >= 3.3
- Понимание базовой структуры Flutter-проекта

---

## Шаг 1 — Создание проекта

```bash
flutter create --org com.example --project-name acp_client acp_client
cd acp_client
```

---

## Шаг 2 — Структура директорий

Создай следующую структуру в `lib/`:

```text
lib/
├── core/
│   ├── di/                     # Dependency Injection
│   │   └── injection.dart
│   ├── error/                  # Типы ошибок
│   │   └── failures.dart
│   └── utils/
│       └── logger.dart
│
├── domain/
│   ├── entities/               # Чистые бизнес-объекты
│   │   ├── session.dart
│   │   ├── acp_message.dart
│   │   └── tool_call.dart
│   ├── repositories/           # Абстрактные интерфейсы
│   │   └── session_repository.dart
│   └── services/               # Абстрактные сервисы
│       └── transport_service.dart
│
├── application/
│   ├── dto/                    # Data Transfer Objects
│   │   └── session_dto.dart
│   └── use_cases/              # Бизнес-сценарии
│       ├── initialize_use_case.dart
│       ├── create_session_use_case.dart
│       ├── load_session_use_case.dart
│       ├── list_sessions_use_case.dart
│       └── send_prompt_use_case.dart
│
├── infrastructure/
│   ├── transport/              # WebSocket и маршрутизация
│   │   ├── websocket_transport.dart
│   │   ├── message_router.dart
│   │   ├── routing_queues.dart
│   │   └── background_receive_loop.dart
│   ├── services/               # Реализации сервисов
│   │   ├── acp_transport_service.dart
│   │   └── permission_handler.dart
│   ├── handlers/               # Обработчики FS/Terminal
│   │   ├── file_system_handler.dart
│   │   └── terminal_handler.dart
│   └── repositories/           # Реализации репозиториев
│       └── in_memory_session_repository.dart
│
└── presentation/
    ├── blocs/                  # flutter_bloc
    │   ├── session/
    │   │   ├── session_bloc.dart
    │   │   ├── session_event.dart
    │   │   └── session_state.dart
    │   ├── chat/
    │   │   ├── chat_bloc.dart
    │   │   ├── chat_event.dart
    │   │   └── chat_state.dart
    │   ├── permission/
    │   │   ├── permission_bloc.dart
    │   │   ├── permission_event.dart
    │   │   └── permission_state.dart
    │   └── terminal/
    │       ├── terminal_bloc.dart
    │       ├── terminal_event.dart
    │       └── terminal_state.dart
    ├── screens/
    │   ├── session_list_screen.dart
    │   └── chat_screen.dart
    └── widgets/
        ├── message_bubble.dart
        ├── tool_call_card.dart
        ├── plan_panel.dart
        └── permission_dialog.dart
```

Создай все директории командой:

```bash
mkdir -p lib/core/{di,error,utils}
mkdir -p lib/domain/{entities,repositories,services}
mkdir -p lib/application/{dto,use_cases}
mkdir -p lib/infrastructure/{transport,services,handlers,repositories}
mkdir -p lib/presentation/{blocs/{session,chat,permission,terminal},screens,widgets}
```

## Шаг 3 — Настройка pubspec.yaml

Замени содержимое `pubspec.yaml`:

```yaml
name: acp_client
description: Flutter client for Agent Client Protocol (ACP)
version: 1.0.0+1

environment:
  sdk: ">=3.3.0 <4.0.0"
  flutter: ">=3.19.0"

dependencies:
  flutter:
    sdk: flutter

  # State Management
  flutter_bloc: ^8.1.6
  bloc: ^8.1.4

  # Dependency Injection
  cherrypick: ^3.0.0
  cherrypick_annotations: ^3.0.0
  cherrypick_flutter: ^3.0.0

  # Data models (иммутабельные классы + JSON)
  freezed_annotation: ^2.4.1
  json_annotation: ^4.9.0

  # WebSocket
  web_socket_channel: ^3.0.1

  # Functional programming (Either для ошибок)
  fpdart: ^1.1.0

  # Navigation
  go_router: ^14.2.7

  # Logging
  structured_log: ^0.1.0

  # UUID генерация
  uuid: ^4.4.2

  # UI Components (общая библиотека проекта)
  codelab_ui_components:
    path: ../../packages/codelab_ui_components

  # Fluent UI (используется в codelab_ui_components)
  fluent_ui: ^4.15.1

  # Дополнительно
  equatable: ^2.0.5
  rxdart: ^0.28.0

dev_dependencies:
  flutter_test:
    sdk: flutter

  # Code generation
  build_runner: ^2.4.12
  freezed: ^2.5.7
  json_serializable: ^6.8.0
  cherrypick_generator: ^3.0.0

  # Testing
  mocktail: ^1.0.4
  bloc_test: ^9.1.7

  # Linting
  flutter_lints: ^4.0.0
```

Установи зависимости:

```bash
flutter pub get
```

---

## Шаг 4 — Настройка analysis_options.yaml

Создай/замени файл `analysis_options.yaml`:

```yaml
include: package:flutter_lints/flutter.yaml

analyzer:
  errors:
    missing_required_param: error
    missing_return: error
  exclude:
    - "**/*.g.dart"
    - "**/*.freezed.dart"

linter:
  rules:
    - always_declare_return_types
    - avoid_dynamic_calls
    - avoid_print
    - prefer_const_constructors
    - prefer_final_fields
    - prefer_final_locals
    - sort_constructors_first
    - unawaited_futures
    - avoid_redundant_argument_values
    - require_trailing_commas
```

---

## Шаг 5 — Настройка build.yaml

Создай файл `build.yaml` для настройки code generation:

```yaml
targets:
  $default:
    builders:
      cherrypick_generator|cherrypick_builder:
        enabled: true
```

## Шаг 6 — Проверка

Запусти анализатор:

```bash
flutter analyze
```

Убедись, что нет критических ошибок. Ошибки о несуществующих файлах нормальны на этом этапе.
