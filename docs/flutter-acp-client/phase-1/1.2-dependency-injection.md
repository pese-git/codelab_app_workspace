# Задача 1.2 — Dependency Injection (cherrypick)

## Цель

Настроить контейнер зависимостей с использованием `cherrypick` внутри `apps/codelab_desktop`. Это Flutter-аналог Python DI-контейнера из референса (`infrastructure/di_container.py`).

## Концепция

В Python-референсе `DIContainer` регистрирует зависимости с тремя скоупами:
- **Singleton** — один экземпляр на всё приложение
- **Transient** — новый экземпляр при каждом запросе
- **Scoped** — один экземпляр на scope (сессию)

В Flutter используем `cherrypick`:
- `.singleton()` → Singleton (один экземпляр на скоуп)
- `.toProvide(() => ...)` без `.singleton()` → Transient (новый экземпляр при каждом `resolve`)
- `scope.openSubScope(...)` → Scoped (новый скоуп для сессии, при закрытии которого все `Disposable` освобождаются)

Иерархия скоупов приложения:

```
rootScope (AppModule)
   └── sessionScope (SessionModule) — создаётся при открытии сессии
```

## Шаг 1 — Создание AppModule

Создай файл `apps/codelab_desktop/lib/core/di/app_module.dart`:

```dart
import 'package:cherrypick/cherrypick.dart';
import 'package:cherrypick_annotations/cherrypick_annotations.dart';

import '../../domain/repositories/session_repository.dart';
import '../../domain/services/transport_service.dart';
import '../../infrastructure/repositories/in_memory_session_repository.dart';
import '../../infrastructure/services/acp_transport_service.dart';
import '../../application/use_cases/initialize_use_case.dart';
import '../../application/use_cases/create_session_use_case.dart';
import '../../application/use_cases/list_sessions_use_case.dart';
import '../../application/use_cases/load_session_use_case.dart';

@module()
class AppModule extends Module {
  @override
  void builder(Scope currentScope) {
    // Infrastructure singletons
    currentScope
        .bind<SessionRepository>()
        .toProvide(() => InMemorySessionRepository())
        .singleton();

    currentScope
        .bind<TransportService>()
        .toProvide(
          () => AcpTransportService(
            permissionHandler: currentScope.resolve(),
          ),
        )
        .singleton();

    // Use Cases (transient — новый экземпляр при каждом resolve)
    currentScope
        .bind<InitializeUseCase>()
        .toProvide(
          () => InitializeUseCase(
            transport: currentScope.resolve<TransportService>(),
          ),
        );

    currentScope
        .bind<CreateSessionUseCase>()
        .toProvide(
          () => CreateSessionUseCase(
            transport: currentScope.resolve<TransportService>(),
            sessionRepo: currentScope.resolve<SessionRepository>(),
          ),
        );

    currentScope
        .bind<ListSessionsUseCase>()
        .toProvide(
          () => ListSessionsUseCase(
            transport: currentScope.resolve<TransportService>(),
            sessionRepo: currentScope.resolve<SessionRepository>(),
          ),
        );

    currentScope
        .bind<LoadSessionUseCase>()
        .toProvide(
          () => LoadSessionUseCase(
            transport: currentScope.resolve<TransportService>(),
            sessionRepo: currentScope.resolve<SessionRepository>(),
          ),
        );
  }
}
```

## Шаг 2 — Настройка structured_log

В `configureDependencies()` настрой вывод логов до инициализации DI:

```dart
// apps/codelab_desktop/lib/core/di/injection.dart
import 'package:cherrypick/cherrypick.dart';
import 'package:structured_log/structured_log.dart';

import 'app_module.dart';

late final Scope rootScope;

void configureDependencies() {
  // Настраиваем structured_log глобально
  StructlogConfiguration.configure(
    output: coloredConsoleOutput, // в debug; для prod — defaultOutput (JSON)
    initialContext: {'app': 'codelab_desktop'},
  );

  rootScope = CherryPick.openRootScope()
    ..installModules([AppModule()]);
}

T resolve<T extends Object>() => rootScope.resolve<T>();
```

> **Ключевое отличие от logger:** логгер больше не является зависимостью. Каждый класс сам создаёт `final _log = getLogger('ClassName')` без конструктора. `StructlogConfiguration` настраивается один раз глобально.

## Шаг 3 — Интеграция с main.dart

Обнови `apps/codelab_desktop/lib/main.dart`, добавив вызов `configureDependencies()` перед запуском приложения:

import 'package:flutter/widgets.dart';

void main() {

## Шаг 4 — Интеграция cherrypick_flutter в дерево виджетов

`cherrypick_flutter` предоставляет `ScopeWidget` — виджет для доступа к скоупу из дерева виджетов.

### Предоставление скоупа в дерево

Обнови `apps/codelab_desktop/lib/app/app.dart`, обернув `FluentApp.router` в `ScopeWidget`:

```dart
import 'package:fluent_ui/fluent_ui.dart';
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:cherrypick_flutter/cherrypick_flutter.dart';
import 'package:go_router/go_router.dart';

import 'dialogs/dialog_host.dart';
import 'mock/mock_data.dart';
import 'navigation/router.dart';
import 'state/app_controller.dart';
import 'state/app_scope.dart';
import 'theme/app_theme.dart';
import '../core/di/injection.dart';

class CodeLabAppBootstrap extends StatefulWidget {
  const CodeLabAppBootstrap({super.key});

  @override
  State<CodeLabAppBootstrap> createState() => _CodeLabAppBootstrapState();
}

class _CodeLabAppBootstrapState extends State<CodeLabAppBootstrap> {
  late final CodeLabAppController _controller;
  late final GoRouter _router;

  @override
  void initState() {
    super.initState();
    _controller = CodeLabAppController(seedWorkspace: buildMockWorkspace());
    _router = buildRouter(_controller);
  }

  @override
  void dispose() {
    _router.dispose();
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return ScopeWidget(
      scope: rootScope,
      child: CodeLabAppScope(
        controller: _controller,
        child: FluentApp.router(
          title: 'CodeLab Desktop',
          debugShowCheckedModeBanner: false,
          themeMode: ThemeMode.light,
          theme: buildAppTheme(),
          darkTheme: buildAppTheme(),
          routerConfig: _router,
          builder: (context, child) {
            return DialogHost(
              child: child ?? const SizedBox.shrink(),
            );
          },
        ),
      ),
    );
  }
}
```

> **Важно:** `ScopeWidget` оборачивает всё дерево, чтобы ACP-зависимости были доступны из любого экрана через `context.scope`.

### Получение зависимостей в виджете

## Шаг 5 — SessionScope (subscope для сессии)

Для зависимостей, специфичных для одной сессии, создаётся подскоуп. При закрытии сессии скоуп закрывается, и все `Disposable`-зависимости освобождаются.

Создай файл `apps/codelab_desktop/lib/core/di/session_module.dart`:

```dart
import 'package:cherrypick/cherrypick.dart';
import 'package:cherrypick_annotations/cherrypick_annotations.dart';

import '../../application/use_cases/send_prompt_use_case.dart';
import '../../application/services/permission_handler.dart';
import '../../domain/services/transport_service.dart';
import '../../domain/repositories/session_repository.dart';
import '../../infrastructure/handlers/file_system_handler.dart';
import '../../infrastructure/handlers/terminal_handler.dart';

@module()
class SessionModule extends Module {
  final String sessionId;

  SessionModule({required this.sessionId});

  @override
  void builder(Scope currentScope) {
    currentScope
        .bind<FileSystemHandler>()
        .toProvide(() => FileSystemHandler())
        .singleton();

    currentScope
        .bind<TerminalHandler>()
        .toProvide(() => TerminalHandler())
        .singleton();

    currentScope
        .bind<PermissionHandler>()
        .toProvide(() => PermissionHandler())
        .singleton();

    currentScope
        .bind<SendPromptUseCase>()
        .toProvide(
          () => SendPromptUseCase(
            transport: currentScope.resolve<TransportService>(),
            sessionRepo: currentScope.resolve<SessionRepository>(),
            fsService: currentScope.resolve<FileSystemHandler>(),
            terminalService: currentScope.resolve<TerminalHandler>(),
          ),
        );
  }
}
```

### Открытие и закрытие SessionScope

```dart
// Открытие при входе в сессию
final sessionScope = rootScope.openSubScope('session_$sessionId')
  ..installModules([SessionModule(sessionId: sessionId)]);

// Закрытие при выходе из сессии
sessionScope.close(); // вызывает Disposable.dispose() у всех singleton
```

## Шаг 6 — Disposable интерфейс

Классы, которые держат ресурсы (WebSocket-соединение, StreamController), должны имплементировать `Disposable`:

```dart
// apps/codelab_desktop/lib/infrastructure/services/acp_transport_service.dart
import 'package:cherrypick/cherrypick.dart';
import '../../domain/services/transport_service.dart';

class AcpTransportService implements TransportService, Disposable {
  // ...

  @override
  Future<void> dispose() async {
    await disconnect();
    _routingQueues.dispose();
  }
}
```

При вызове `scope.close()` cherrypick автоматически вызовет `dispose()` у всех зарегистрированных `Disposable`-синглтонов в этом скоупе.

## Шаг 7 — Использование логгера в классах

С `structured_log` логгер не является DI-зависимостью. Каждый класс создаёт свой экземпляр:

```dart
import 'package:structured_log/structured_log.dart';

class AcpTransportService implements TransportService {
  final _log = getLogger('AcpTransportService');

  Future<void> connect() async {
    _log.info('Connecting...', context: {'host': _config.host});
    // ...
  }
}
```

Для добавления контекста к логам (например, sessionId):

```dart
final _sessionLog = _log.bind({'session_id': sessionId});
_sessionLog.info('Session started');
```

## Справочник: API cherrypick

| Операция | Код |
|---|---|
| Открыть корневой скоуп | `CherryPick.openRootScope()` |
| Установить модули | `scope.installModules([AppModule()])` |
| Зарегистрировать singleton | `scope.bind<T>().toProvide(() => ...).singleton()` |
| Зарегистрировать transient | `scope.bind<T>().toProvide(() => ...)` |
| Получить зависимость | `scope.resolve<T>()` |
| Открыть подскоуп | `scope.openSubScope('name')` |
| Закрыть скоуп | `scope.close()` |
| Скоуп в виджете | `context.scope` (cherrypick_flutter) |
| Освобождение ресурсов | `implements Disposable` + `dispose()` |
