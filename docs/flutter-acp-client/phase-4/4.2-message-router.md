# Задача 4.2 — Message Router & Routing Queues

## Цель

Реализовать маршрутизацию входящих сообщений по очередям. Это ключевая инфраструктура для конкурентной обработки нескольких запросов на одном WebSocket соединении.

## Концепция

Аналог Python: `infrastructure/services/message_router.py` и `routing_queues.py`.

Проблема: несколько Use Cases могут одновременно ожидать ответ на разные request_id. Background Loop получает все сообщения, Router определяет тип, Queues доставляют в нужное место.

```
WebSocket stream
       ↓
BackgroundReceiveLoop
       ↓
   MessageRouter
  /      |      \
Response Permission Notification
Queue    Queue    Queue
  ↓        ↓         ↓
Use      Permission  on_update
Case     Handler    callback
```

## Шаг 1 — Routing Queues

Создай файл `lib/infrastructure/transport/routing_queues.dart`:

```dart
import 'dart:async';

/// Набор очередей для маршрутизации входящих сообщений
///
/// Аналог Python: infrastructure/services/routing_queues.py
class RoutingQueues {
  // Очереди для RPC ответов: requestId → StreamController
  final Map<String, StreamController<Map<String, dynamic>>> _responseQueues = {};

  // Очередь для уведомлений (session/update и прочие notifications)
  final StreamController<Map<String, dynamic>> _notificationController =
      StreamController.broadcast();

  // Очередь для permission requests
  final StreamController<Map<String, dynamic>> _permissionController =
      StreamController.broadcast();

  Stream<Map<String, dynamic>> get notifications =>
      _notificationController.stream;

  Stream<Map<String, dynamic>> get permissionRequests =>
      _permissionController.stream;

  /// Получает или создаёт очередь ответов для request_id
  Stream<Map<String, dynamic>> getOrCreateResponseStream(String requestId) {
    if (!_responseQueues.containsKey(requestId)) {
      _responseQueues[requestId] =
          StreamController<Map<String, dynamic>>.broadcast();
    }
    return _responseQueues[requestId]!.stream;
  }

  /// Добавляет ответ в очередь для request_id
  void putResponse(String requestId, Map<String, dynamic> message) {
    final controller = _responseQueues[requestId];
    if (controller != null && !controller.isClosed) {
      controller.add(message);
    }
  }

  /// Добавляет notification в общую очередь
  void putNotification(Map<String, dynamic> message) {
    if (!_notificationController.isClosed) {
      _notificationController.add(message);
    }
  }

  /// Добавляет permission request в отдельную очередь
  void putPermissionRequest(Map<String, dynamic> message) {
    if (!_permissionController.isClosed) {
      _permissionController.add(message);
    }
  }

  /// Удаляет очередь ответов для request_id (cleanup после получения ответа)
  void cleanupResponseQueue(String requestId) {
    final controller = _responseQueues.remove(requestId);
    controller?.close();
  }

  /// Закрывает все очереди
  Future<void> dispose() async {
    for (final controller in _responseQueues.values) {
      await controller.close();
    }
    _responseQueues.clear();
    await _notificationController.close();
    await _permissionController.close();
  }
}
```

## Шаг 2 — Message Router

Создай файл `lib/infrastructure/transport/message_router.dart`:

```dart
import 'routing_queues.dart';

/// Маршрутизатор входящих JSON-RPC сообщений
///
/// Определяет тип сообщения и направляет в соответствующую очередь.
/// Аналог Python: infrastructure/services/message_router.py
class MessageRouter {
  final RoutingQueues _queues;

  MessageRouter(this._queues);

  /// Маршрутизирует входящее сообщение
  void route(Map<String, dynamic> message) {
    final method = message['method'] as String?;
    final id = message['id'];

    if (method != null) {
      // Это request или notification от сервера
      if (method == 'session/update') {
        // Notification — в очередь уведомлений
        _queues.putNotification(message);
      } else if (method == 'session/request_permission') {
        // Permission request — в отдельную очередь
        _queues.putPermissionRequest(message);
      } else if (id != null) {
        // Server→Client RPC (fs/*, terminal/*) — в очередь уведомлений
        // (будет обработан в request_with_callbacks)
        _queues.putNotification(message);
      } else {
        // Прочие notifications
        _queues.putNotification(message);
      }
    } else if (id != null) {
      // Это response на наш request
      final requestId = id.toString();
      _queues.putResponse(requestId, message);
    }
  }
}
```

## Критерии готовности

- [ ] `RoutingQueues` реализован с отдельными потоками для response/notification/permission
- [ ] `MessageRouter` маршрутизирует все типы сообщений
- [ ] `cleanupResponseQueue` вызывается после получения ответа
- [ ] `dispose()` закрывает все StreamController-ы
