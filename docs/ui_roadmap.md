# 🗺️ Дорожная карта реализации UI

Этот документ отслеживает пошаговую разработку библиотеки компонентов `codelab_desktop`.

## Этап 1: Инфраструктура и Основа
- [ ] **Настройка темы**: Определение `FluentThemeData` (цвета: поверхность, фон, акцент, текст) на основе референсного приложения.
- [ ] **Дизайн-токены**: Создание файла констант для отступов, размеров и типографики.

## Этап 2: Оболочка приложения (Navigation & Layout)
- [ ] **Navigation Pane (Боковая панель)**: Реализация `NavigationPane` с использованием `fluent_ui`, поддерживающая режимы `compact` (узкая полоса) и `expanded` (панель).
- [ ] **Title Bar (Заголовок окна)**: Реализация области управления окном (Свернуть, Развернуть, Закрыть).
- [ ] **Основной контейнер макета**: Логика переключения между `Home` и `Session`.

## Этап 3: Экран Home
- [ ] **Карточка проекта**: UI для представления одного проекта.
- [ ] **Empty State (Пустое состояние)**: Заполнитель, когда проектов нет.
- [ ] **Быстрые действия**: Кнопки "Новый проект", "Последние".

## Этап 4: Экран Сессии (Рабочая зона)
- [ ] **Message Timeline (Лента сообщений)**: Прокручиваемый список виджетов `ChatMessage` (различие между Пользователем и AI).
- [ ] **Prompt Composer (Поле ввода)**: Многофункциональная зона ввода (текст, вложения файлов, выбор инструментов).
- [ ] **Session Side Panel (Боковая панель сессии)**: Панель с контекстной информацией (активные файлы, параметры сессии).
- [ ] **File Tabs System (Система вкладок)**: Вкладки для файлов, ревью и терминала.

## Этап 5: Продвинутые панели
- [ ] **Интегрированный терминал**: Обертка для интерфейса терминала.
- [ ] **File Tree (Дерево файлов)**: Реализация дерева рабочих пространств/папок.
